# מצב ריכוז — תוסף חסימת הסחות דעת

תוסף דפדפן: בוחרים כרטיסייה אחת שנשארת פתוחה, קובעים כמה זמן להתמקד ומה מתכננים לעשות, והתוסף חוסם (מנווט לעמוד חסימה) כל כרטיסייה/חלון אחר — כולל כרטיסיות וחלונות חדשים — עד שהזמן נגמר או שמסמנים שסיימתם. כולל הפסקות עם טיימר נפרד, אפשרות להאריך זמן, חגיגת קונפטי בסיום, וביטול מלא בכל רגע.

נבנה ב-JavaScript רגיל בלבד (ללא React/בנדלר, 0 תלויות בזמן ריצה) — קל לקרוא, לבדוק ולטעון כ"unpacked".

## מבנה
- `extension/` — קוד המקור המשותף לכל הדפדפנים.
- `manifest.chrome.json` / `manifest.firefox.json` — ה-manifest הספציפי לכל דפדפן (נבדלים רק באופן טעינת ה-background).
- `build.js` — מרכיב את `dist/chrome` ו-`dist/firefox` (עותק של `extension/` + ה-manifest המתאים).

## בנייה
```
npm run build            # בונה גם chrome וגם firefox
npm run build:chrome     # רק chrome/edge/brave
npm run build:firefox    # רק firefox
```

## טעינה לדפדפן

### Chrome / Edge / Brave
1. `npm run build:chrome`
2. הדביקו בשורת הכתובות של הדפדפן (לא בגוגל): `chrome://extensions` (או `edge://extensions`, `brave://extensions`) ולחצו Enter
3. הפעילו את המתג "מצב מפתח" (Developer mode) — המיקום המדויק בעמוד משתנה בין גרסאות דפדפן
4. לחצו "טעינת תוסף לא ארוז" (Load unpacked) ובחרו את התיקייה `dist/chrome` (לא קובץ בודד בתוכה — את התיקייה עצמה)

### Firefox
1. `npm run build:firefox`
2. הדביקו בשורת הכתובות: `about:debugging#/runtime/this-firefox` ולחצו Enter
3. "טעינת תוסף זמנית" (Load Temporary Add-on) ובחרו את הקובץ `dist/firefox/manifest.json`

> תוסף זמני ב-Firefox נמחק כשסוגרים את הדפדפן — לשימוש קבוע צריך לחתום את התוסף דרך addons.mozilla.org.

## שימוש
1. לוחצים על אייקון התוסף, בוחרים כרטיסייה מהרשימה, קובעים משך זמן, כותבים מה מתכננים לעשות ומספר הפסקות מתוכנן, ולוחצים "התחלת מיקוד".
2. כל שאר הכרטיסיות (וחלון חדש שנפתח) עוברות לעמוד חסימה עם ספירה לאחור וקישור חזרה לכרטיסייה הממוקדת.
3. אפשר לקחת "הפסקה" (עם משך זמן נפרד) — הטיימר הראשי מושהה וכל הכרטיסיות משוחררות עד סוף ההפסקה.
4. כשהזמן נגמר (או בלחיצה על "סיימתי" בכל שלב) — מופיע חלון שאלה על הכרטיסייה הממוקדת: "האם סיימת?". תשובה "כן" מציגה חגיגת קונפטי ומשחזרת את כל הכרטיסיות. תשובה "לא" מאפשרת להאריך זמן ולהמשיך.
5. אפשר לבטל את מצב הריכוז בכל רגע (כפתור "ביטול") — זה מוחק את התוכנית, הטיימר והחסימות ומשחזר את כל הכרטיסיות לעמוד המקורי שלהן.

## הפצה לחברות/חברים דרך GitHub (חינם, בלי חנות תוספים)
הפרויקט כולל שני חלקים שמכינים הפצה מלאה דרך GitHub בלבד:

1. **`.github/workflows/release.yml`** — בכל push ל-`main`, GitHub Actions בונה את `dist/chrome` ו-`dist/firefox`, אורז אותם כ-ZIP, ומפרסם אותם כ-GitHub Release. הקישורים `https://github.com/<user>/<repo>/releases/latest/download/focus-mode-chrome.zip` (ובהתאמה `-firefox.zip`) תמיד מצביעים על הגרסה העדכנית ביותר, גם כשמעלים שינויים חדשים.
2. **`docs/index.html`** — דף נחיתה קטן בעברית עם כפתורי הורדה והוראות התקנה לכל דפדפן, מוכן לפרסום כ-GitHub Pages.

### איך להפעיל את זה בפועל
1. יוצרים ריפו ב-GitHub ודוחפים אליו את התיקייה הזו (`git init`, `git add`, `git commit`, `git remote add origin ...`, `git push`).
2. בקובץ `docs/index.html`, בשורה עם `const REPO = "YOUR_GITHUB_USERNAME/YOUR_REPO_NAME";` — מחליפים לשם המשתמש/ריפו האמיתיים שלכם.
3. ב-GitHub: Settings → Actions → General → מוודאים ש-Workflow permissions מוגדר "Read and write permissions" (נדרש כדי שה-Action יוכל לפרסם Release).
4. ב-GitHub: Settings → Pages → Source: "Deploy from a branch" → בוחרים את ה-branch `main` ואת התיקייה `/docs`. אחרי דקה-שתיים יהיה לכם קישור כמו `https://<user>.github.io/<repo>/`.
5. שולחים את קישור ה-GitHub Pages לחברות — הן ילחצו על כפתור ההורדה המתאים לדפדפן שלהן ויעקבו אחרי ההוראות בדף (עדיין צריך "מצב מפתח" + "טעינת תוסף לא ארוז", כי זו לא התקנה דרך חנות תוספים רשמית).

## הערה על הרשאות
התוסף מבקש הרשאת `<all_urls>` — נחוצה כדי להזריק את חלון "סיימת?" לכרטיסייה הממוקדת (שיכולה להיות כל אתר) וכדי לנווט כרטיסיות אחרות לעמוד החסימה. זו אותה רמת הרשאה שיש לתוספי חסימת-הסחות-דעת מוכרים. אם בעתיד תרצו לפרסם בחנויות התוספים, יש להסביר זאת בתיאור התוסף.
