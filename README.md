# 🎯 מצב ריכוז

## ✨ מה התוסף עושה

- **בחירת כרטיסיית מיקוד** — התוסף מציג רשימה של כל הכרטיסיות הפתוחות ומאפשר לבחור איזו מהן תישאר נגישה.
- **חסימת כל השאר** — כל כרטיסייה אחרת (וגם כרטיסייה/חלון חדש שמנסים לפתוח) מנווטת לעמוד חסימה עם ספירה לאחור, במקום להיסגר ולאבד תוכן.
- **טיימר + תוכנית** — קובעים מראש כמה זמן להתמקד וכותבים (בלי הגבלת אורך) מה מתכננים להספיק בזמן הזה.
- **הפסקות עם טיימר נפרד** — לוקחים "הפסקה" (כמו הפסקת אוכל) עם משך זמן משלה; הטיימר הראשי מושהה וכל הכרטיסיות משתחררות עד שההפסקה נגמרת.
- **בדיקת סיום חכמה** — כשהזמן נגמר, או בלחיצה על "סיימתי" בכל שלב, מופיעה שאלה על הכרטיסייה הממוקדת: "האם סיימת?". תשובה חיובית מציגה חגיגת קונפטי 🎉 ומשחזרת את כל הכרטיסיות לכתובת המקורית שלהן; תשובה שלילית מאפשרת להאריך את הזמן ולהמשיך.
- **ביטול מלא בכל רגע** — כפתור "ביטול" מוחק את התוכנית, הטיימר וכל החסימות, ומחזיר את כל הכרטיסיות למצבן המקורי.

## 🌐 דפדפנים נתמכים
Chrome, Microsoft Edge, Brave ו-Firefox — מאותו קוד מקור, עם שני קבצי manifest (הבדל טכני בלבד באופן טעינת ה-background).

## 🚀 התקנה
הדרך הפשוטה ביותר היא דרך **[דף ההתקנה](https://shira2299.github.io/focus-mode-extension/)**: מורידים ZIP מתאים לדפדפן ועוקבים אחרי ההוראות שם (טעינת "תוסף לא ארוז" דרך מצב מפתח — זה לא דורש חנות תוספים או תשלום).

מי שמעוניין לבנות מקור בעצמו — ראו את החלק "פיתוח" למטה.

## 🕹️ שימוש
1. לוחצים על אייקון התוסף, בוחרים כרטיסייה מהרשימה, קובעים משך זמן, כותבים מה מתכננים לעשות ומספר הפסקות מתוכנן, ולוחצים "התחלת מיקוד".
2. כל שאר הכרטיסיות (וחלון חדש שנפתח) עוברות לעמוד חסימה עם ספירה לאחור וקישור חזרה לכרטיסייה הממוקדת.
3. אפשר לקחת "הפסקה" (עם משך זמן נפרד) — הטיימר הראשי מושהה וכל הכרטיסיות משוחררות עד סוף ההפסקה.
4. כשהזמן נגמר (או בלחיצה על "סיימתי" בכל שלב) — מופיעה שאלה על הכרטיסייה הממוקדת: "האם סיימת?". תשובה "כן" מציגה חגיגת קונפטי ומשחזרת את כל הכרטיסיות. תשובה "לא" מאפשרת להאריך זמן ולהמשיך.
5. אפשר לבטל את מצב הריכוז בכל רגע (כפתור "ביטול") — זה מוחק את התוכנית, הטיימר והחסימות ומשחזר את כל הכרטיסיות לעמוד המקורי שלהן.

## 🏗️ מבנה הפרויקט
```
extension/            קוד המקור המשותף לכל הדפדפנים
├── background.js      service worker — הלוגיקה המרכזית (חסימה, טיימרים, הודעות)
├── popup/              הממשק שנפתח בלחיצה על אייקון התוסף
├── blocked/            עמוד החסימה שמוצג בכרטיסיות שאינן הכרטיסייה הממוקדת
├── content/            overlay שמוזרק לכרטיסייה הממוקדת (שאלת סיום + קונפטי)
├── lib/                קוד עזר משותף (storage, תאימות בין דפדפנים, אנימציית קונפטי)
└── icons/

manifest.chrome.json    manifest ל-Chrome / Edge / Brave
manifest.firefox.json   manifest ל-Firefox
build.js                מרכיב dist/chrome ו-dist/firefox מתוך extension/
tests/e2e-check.js      בדיקה אוטומטית מקצה לקצה עם Playwright
docs/index.html         דף ההתקנה (מתפרסם דרך GitHub Pages)
```

התוסף נכתב ב-JavaScript רגיל בלבד — בלי React ובלי בנדלר, וללא שום תלות בזמן ריצה — כדי שיישאר קל לקריאה, לבדיקה ולביקורת קוד.

## 🛠️ פיתוח

### בנייה מקומית
```
npm run build            # בונה גם chrome וגם firefox
npm run build:chrome     # רק chrome/edge/brave
npm run build:firefox    # רק firefox
```
זה יוצר את `dist/chrome` ו-`dist/firefox` — תיקיות מוכנות לטעינה כ"תוסף לא ארוז" (Load unpacked) דרך מצב מפתח בדפדפן.

### בדיקות
```
npm install
npx playwright install chromium
npm run test:e2e
```
מריץ Chromium אמיתי עם התוסף טעון, ועובר על כל התרחישים המרכזיים (חסימת כרטיסיות, הפסקה, סיום, שחזור, ביטול). צילומי מסך נשמרים ב-`tests/screenshots/`.

### פרסום גרסאות
כל push ל-`main` מפעיל את `.github/workflows/release.yml`, שבונה את שני היעדים, אורז אותם כ-ZIP ומפרסם אותם כ-GitHub Release — דף ההתקנה מקשר תמיד לגרסה העדכנית ביותר באופן אוטומטי.

## 🔒 הרשאות ופרטיות
התוסף מבקש הרשאת `<all_urls>` — נחוצה כדי להציג את שאלת "סיימת?" על הכרטיסייה הממוקדת (שיכולה להיות כל אתר) וכדי לנווט כרטיסיות אחרות לעמוד החסימה. זו אותה רמת הרשאה שיש לתוספי חסימת-הסחות-דעת מוכרים אחרים. כל הנתונים (תוכנית, היסטוריית סשנים) נשמרים מקומית בדפדפן בלבד ואינם נשלחים לשום שרת חיצוני.
