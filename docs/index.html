🌐 התקנה ב-Chrome / Edge / Brave

  1. מורידים את קובץ ה-ZIP למעלה ומחלצים אותו לתיקייה.
  2. פותחים chrome://extensions (או edge://extensions / brave://extensions).
  3. מפעילים "מצב מפתח" (Developer mode) בפינה.
  4. לוחצים "טעינת תוסף לא ארוז" (Load unpacked) ובוחרים את התיקייה שחילצתם.

🦊 התקנה ב-Firefox

  1. מורידים את קובץ ה-ZIP ומחלצים אותו לתיקייה.
  2. פותחים about:debugging#/runtime/this-firefox.
  3. לוחצים "טעינת תוסף זמנית" (Load Temporary Add-on) ובוחרים את הקובץ manifest.json בתוך התיקייה.
  4. שימו לב: תוסף זמני נעלם כשסוגרים את פיירפוקס — צריך לטעון אותו מחדש בכל פתיחה.
