💡 שימו לב: תוסף כזה לא "מריצים" ולא מתקינים עם הפעלה כפולה על קובץ — פשוט בוחרים את התיקייה בתוך הדפדפן עצמו, כמו בהוראות למטה.

🌐 התקנה ב-Chrome / Edge / Brave

  1. מורידים את קובץ ה-ZIP למעלה, ומחלצים אותו לתיקייה (קליק ימני על קובץ ה-ZIP ← "חילוץ הכול" / Extract All).
  2. פותחים את הדפדפן. מעתיקים את הכתובת chrome://extensions (למשתמשי Edge: edge://extensions, ל-Brave: brave://extensions) ומדביקים אותה בשורת הכתובות למעלה (איפה שכותבים כתובות אתרים) — לא לחפש בגוגל! — ולוחצים Enter.
  3. בעמוד שנפתח מחפשים מתג עם הכיתוב "Developer mode" (מצב מפתח) — המיקום המדויק משתנה קצת בין גרסאות דפדפן (לפעמים למעלה מימין, לפעמים בתפריט בצד שמאל) — ומפעילים אותו.
  4. אחרי ההפעלה יופיעו כפתורים חדשים; לוחצים על "Load unpacked" (טעינת תוסף לא ארוז).
  5. בוחרים את התיקייה שחילצתם בשלב 1 (לא את קובץ ה-ZIP המקורי!) ולוחצים "Select Folder" / "בחירת תיקייה". התוסף נטען מיד ומופיע ברשימה — זהו, אין שום דבר נוסף להריץ או להתקין.
  6. כדי להשתמש בו: לוחצים על אייקון הפאזל 🧩 למעלה מימין בדפדפן, ואז על סיכת הנעיצה 📌 ליד "מצב ריכוז" כדי שהוא יופיע קבוע בסרגל הכלים.

🦊 התקנה ב-Firefox

  1. מורידים את קובץ ה-ZIP ומחלצים אותו לתיקייה.
  2. מעתיקים את הכתובת about:debugging#/runtime/this-firefox ומדביקים אותה בשורת הכתובות למעלה, ולוחצים Enter.
  3. לוחצים "טעינת תוסף זמנית" (Load Temporary Add-on) ובוחרים את הקובץ manifest.json שנמצא בתוך התיקייה שחילצתם.
  4. שימו לב: תוסף זמני נעלם כשסוגרים את פיירפוקס — צריך לחזור על שלבים 2–3 בכל פתיחה מחדש של הדפדפן.
